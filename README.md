# TWENTY

20장 카드의 공개 정보를 보고 홀짝 또는 무늬를 예측하는 브라우저 미니게임.

## 실행

Node.js 22.12 이상(또는 지원되는 최신 LTS)을 사용합니다.

```sh
npm install
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

## 현재 범위

기본 3라운드부터 선택형 HIGH DECK 완주·점수 저장·재시작까지 플레이할 수 있습니다.
강제 시간 제한 없이 3라운드를 모두 진행하고 마지막 정산 뒤 승패를 판정합니다.
플레이 시간은 내부에서 측정해 결과에만 표시하며 일시정지와 포커스 이탈 시간은 제외합니다.
한 판에 한 번 베팅액과 반환액을 두 배 기준으로 계산하는 DOUBLE DOWN을 사용할 수 있습니다.
앞의 두 장을 공개하기 전에는 선택 카드를 다시 눌러 취소할 수 있습니다.
카드 공개·결과 효과와 즉시 적용되는 `움직임 줄이기` 선택권을 제공합니다.
누적 완료·성공·HIGH DECK 완주 횟수·최고 코인과 움직임 설정은 브라우저에 저장합니다.
현재 판은 재접속과 새 게임에서 초기화하며, 빈 값·손상값·저장소 오류에는 기본값으로 안전하게 복구합니다.
기본 게임 성공 뒤에는 6~10 카드가 추가되는 HIGH DECK에 선택적으로 도전할 수 있습니다.
HIGH DECK은 20·40·60코인 베팅과 숫자 예측을 제공하며, 매 라운드 점수를 확정하거나 계속 도전할 수 있습니다.
PC 경계·10분 실행·난이도 20회 비교를 완료했으며 공개 배포를 준비했습니다.

- `src/game/engine.ts`: 화면과 독립된 게임 계산
- `src/game/engine.test.ts`: 핵심 계산 검사
- `src/game/session.ts`: 시간과 입력을 처리하는 순수 상태 전환 함수
- `src/game/session.test.ts`: 한 판 진행과 경계 조건 검사
- `src/App.tsx`: 기본 화면
- `docs/rules.md`: 확정 규칙과 초기 후보 설정

개발 서버는 로컬 확인용이며 공개 제출 주소가 아닙니다.
