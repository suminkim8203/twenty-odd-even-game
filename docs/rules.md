# 게임 규칙과 구현 범위

- React + TypeScript + Vite로 구현하는 브라우저 전용 게임.
- 스페이드·클럽·하트·다이아 각각 A(1)~5, 총 20장.
- 3장을 중복 없이 선택하고 앞의 2장 공개 후 마지막 카드를 예측한다.
- 홀짝 또는 무늬 중 한 조건에만 베팅한다.
- 확률의 분모는 현재 라운드 시작 덱에서 공개된 2장을 제외한 수다. 숨겨진 선택 카드도 포함한다.
- 원금 포함 반환액 = floor(베팅액 × 가능한 카드 수 / 적중 카드 수). UI에도 이 정수 반환액을 표시한다.
- 적중 가능한 카드가 0장이면 해당 예측을 금지한다.
- 사용한 3장은 다음 라운드에서 제외한다. 매 새 게임에는 20장을 복원한다.
- 한 판 동안 20장의 화면 위치는 고정한다. 사용한 카드는 원래 자리에서 앞면으로 남고 선택할 수 없다.
- 앞의 두 장을 공개하기 전에는 선택한 카드를 다시 눌러 취소할 수 있다. 공개 후 선택을 확정한다.
- 카드 공개와 결과에는 짧은 움직임 효과를 적용하며, 공개 화면의 `움직임 줄이기`로 즉시 줄일 수 있다.
- 3라운드를 모두 진행하고 마지막 정산 뒤 130코인 이상이면 성공, 미만이면 실패한다.
- 강제 시간 제한은 없다. 시작부터 최종 결과까지 시간을 내부에서 측정하고 결과 화면에만 표시한다.
- 포커스 이탈과 일시정지 시간은 최종 플레이 시간에서 제외한다.
- 목표에 먼저 도달해도 게임을 끝내지 않고 `잠정 통과` 상태로 표시한다.
- 한 판에 한 번 DOUBLE DOWN을 선택해 베팅액과 반환액을 두 배 기준으로 계산할 수 있다.
- 베팅 확정 후 마지막 카드는 1.4초 뒤 공개한다. 움직임 줄이기에서는 즉시 공개한다.
- 최종 설정: 시작 100코인, 목표 130코인, 베팅 10/20/30코인. 목표 150코인과 130코인을 10회씩 비교해 정했다.
- 난이도 비교에서는 목표 코인만 변경한다. 카드 규칙과 나머지 설정은 고정한다.
- 가상 코인은 게임 점수이며 충전·현금화 기능은 없다.

## 저장 범위

- 새 게임과 재접속에서 초기화: 현재 코인, 라운드, 덱, 선택 카드, DOUBLE DOWN 사용 여부, 판 기록, 플레이 시간.
- 재접속 뒤 보존: 완료한 판 수, 성공 횟수, HIGH DECK 완주 횟수, 최고 종료 코인, 움직임 줄이기 설정.
- 이전 저장 형식은 기존 기록을 유지하고 HIGH DECK 완주 0회인 새 형식으로 자동 변환한다.
- 저장값이 없거나 비어 있으면 선언된 기본값으로 시작한다.
- JSON 손상, 자료형 오류, 음수 또는 논리적으로 불가능한 값은 기본값으로 복구하고 저장소도 고친다.
- 저장소 접근이 차단돼도 메모리 기본값으로 게임을 계속한다.
- 저장 초기화는 보존 기록과 움직임 설정을 함께 기본값으로 되돌린다.

## HIGH DECK 보너스

- 기본 3라운드에서 성공 상태에 도달한 뒤 `점수 확정` 또는 `HIGH DECK 도전`을 선택한다.
- 기본 성공은 HIGH DECK 결과와 관계없이 즉시 완료 기록에 반영한다.
- 도전 시 기본 덱에 남은 11장에 각 무늬의 6~10 카드 20장을 추가해 31장으로 시작한다.
- 사용된 앞면 9장은 원래 위치에 두고, 기존 뒷면 11장과 추가 카드 20장은 함께 섞어 빈 31칸 전체에 다시 배치한다.
- 따라서 특정 줄이나 위치만으로 카드가 1~5인지 6~10인지 구분할 수 없다.
- 기존의 홀짝·무늬 예측에 무늬와 관계없이 A~10 중 하나를 맞히는 숫자 예측을 추가한다.
- 베팅액은 20·40·60코인이며 DOUBLE DOWN은 사용할 수 없다.
- 매 보너스 라운드 뒤 점수를 확정하거나 계속 도전할 수 있다.
- 점수 확정 또는 덱 완주 때만 HIGH DECK 점수가 최고 코인 기록에 반영된다.
- 베팅 가능 코인이 부족해 종료되면 기본 성공은 유지하지만 HIGH DECK 최고 점수는 갱신하지 않는다.
- 31장에서 3장씩 10라운드를 진행해 한 장이 남으면 그 카드를 공개하고 자동으로 점수를 확정한다.
- 완주 화면에는 최종 스코어, 최고 코인 기록, 누적 HIGH DECK 완주 횟수와 전체 플레이 시간을 표시한다.

## 구현 상태

전체 플레이 흐름, 저장과 복구, 시간 관리, 움직임 선택권, HIGH DECK과 최종 디자인까지 구현했다.
