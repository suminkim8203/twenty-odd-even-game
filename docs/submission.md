# 과제 2 제출문

## 주소

- 결과물 주소: https://suminkim8203.github.io/twenty-odd-even-game/
- 소스 주소: https://github.com/suminkim8203/twenty-odd-even-game

## 짧은 확인 방법 4줄

1. 위치 — 결과물 주소를 새 시크릿 창에서 엽니다.
2. 행동 — `게임 시작` → 뒷면 카드 3장 선택 후 `앞의 두 장 공개` → 베팅액과 예측을 골라 `베팅 확정`을 누릅니다.
3. 통과 모습 — 마지막 카드와 코인 변화가 한 번 표시되고, 3라운드 뒤 성공 또는 실패 화면과 재시작 버튼이 보입니다.
4. 안 될 때 모습 — 조작이 반영되지 않거나 결과 화면 대신 오류·빈 화면이 보이고, 재시작 뒤에도 100코인·1라운드로 돌아오지 않습니다.

## AI와 나의 판단 3줄

1. AI에게 맡긴 일 — React 구현, 확률·배당·상태 로직, 자동 검사, PC 경계 검사와 제출 자료 초안을 맡겼습니다.
2. 직접 판단한 일 — 카드 3장 흐름, 3라운드 의무 진행, HIGH DECK 규칙, 긴장감을 위한 DOUBLE DOWN과 최종 기록 구성을 직접 선택했습니다.
3. AI 제안을 따르지 않은 일 — 처음 제안된 강제 30초 타이머는 생각할 시간을 줄여 재미를 해친다고 판단해 사용하지 않고 최종 플레이 시간만 기록했습니다.
