- `npm run build`: TypeScript 검사 및 Vite 빌드 성공.
- 브라우저 별도 검사 탭에서 시작, 카드 3장 선택, 앞 2장 공개, 홀수 베팅을 수행.
- 공개 카드 ♠A·♠4, 결과 ♣A. 20코인 베팅에서 32코인 반환, 잔액 112 확인.
- 다음 라운드에서 카드 17장, 라운드 2, 선택 카드 초기화 확인.
- 일시정지 시 8.1초에서 멈추고 재개 직후 8.0초로 이어짐 확인.

- 실패 후 재시작: 100코인, 1라운드, 20장, 이번 판 기록 초기화 확인.

> 이 문서 앞부분은 개발 중간 기록이다. 최종 과제 검사는 문서 아래의 `최종 PC 경계 검사`, `난이도 20회 비교`, `저장·효과·공개 안전`을 기준으로 한다.

## 2026-09-07 시간 규칙 변경

> 아래 10초 규칙은 이후 `최종 3라운드 구성`에서 강제 시간 제한 없음으로 대체했다.

- 기존 한 판 공통 30초 타이머를 라운드별 베팅 판단 10초로 변경했다.
- 카드 선택과 결과 확인 중에는 시간이 흐르지 않는다.
- 3라운드의 최대 판단 시간 합계는 30초다.
- 판단 시간 종료, 일시정지와 재개 경계 단위 검사를 갱신했고 14개 테스트와 빌드가 통과했다.

## 2026-09-07 선택 수정과 효과

- 공개 전 선택 카드를 다시 누르면 취소되고, 세 장을 고른 뒤에도 선택된 카드만 취소할 수 있음을 브라우저에서 확인했다.
- 공개 후에는 카드 선택 단계가 끝나므로 선택을 변경할 수 없다.
- 카드 공개, 선택, 결과 등장에 짧은 움직임 효과를 추가했다.
- `움직임 줄이기`를 켜면 화면 전체의 애니메이션과 전환 시간이 즉시 최소화된다.
- 15개 단위 테스트와 빌드가 통과했고, 브라우저 콘솔 오류는 0건이었다.

## 2026-09-07 사용 카드 보드 변경

- 한 판 동안 섞인 20장의 화면 위치를 고정했다.
- 라운드가 끝난 뒤 사용한 3장은 해당 위치에서 실제 무늬와 숫자가 보이는 앞면으로 유지된다.
- 앞면 카드는 비활성화되어 다음 라운드에서 다시 선택할 수 없다.
- 브라우저에서 1라운드 완료 후 2라운드의 20칸, 앞면 3장, 선택 가능한 뒷면 17장을 확인했다.
- 테스트 14개와 빌드가 통과했고 브라우저 콘솔 오류는 0건이었다.

## 2026-09-07 최종 3라운드 구성

- 강제 판단 시간을 제거하고 시작부터 최종 결과까지의 플레이 시간만 내부에서 측정한다.
- 포커스 이탈과 일시정지 시간은 측정에서 제외하고, 최종 결과 화면에만 시간을 표시한다.
- 목표를 먼저 넘어도 `잠정 통과`로 표시하며 3라운드 마지막 정산 뒤 승패를 결정한다.
- DOUBLE DOWN은 한 판에 한 번만 가능하며 실제 베팅액과 반환액을 두 배 기준으로 계산한다.
- 베팅 확정 후 1.4초 동안 마지막 카드 공개 효과를 실행한다. 움직임 줄이기에서는 대기를 제거한다.
- 자동 검사 16개와 빌드가 통과했다.
- 브라우저에서 DOUBLE DOWN 사용·재사용 차단·3라운드 최종 실패·최종 시간 표시를 확인했다.
- 카드 공개 효과를 포함한 전체 3라운드 검사 플레이는 24.2초로 완료됐고 콘솔 오류는 0건이었다.

## 2026-09-07 저장과 복구

- 완료한 판 수, 성공 횟수, 최고 종료 코인, 움직임 줄이기 설정을 `localStorage`에 보존한다.
- 현재 판의 코인·라운드·카드·DOUBLE DOWN·시간은 저장하지 않는다.
- 없음·빈 문자열·깨진 JSON·자료형 오류·음수·완료 횟수보다 큰 성공 횟수 검사를 포함해 자동 검사 24개가 통과했다.
- 브라우저에서 한 판을 완료한 뒤 재접속해 완료 1회·최고 105코인·움직임 줄이기 설정이 유지됨을 확인했다.
- 같은 재접속에서 현재 판은 100코인·1라운드·선택 카드 없음으로 초기화됐다.
- 저장 초기화의 확인 단계를 거친 뒤 재접속해 완료 0회·최고 기록 없음·움직임 줄이기 꺼짐을 확인했다.
- 저장 검사 중 브라우저 콘솔 오류는 0건이었다.

## 2026-09-07 HIGH DECK

- 기본 게임 성공 전에는 HIGH DECK에 진입할 수 없고, 성공 화면에서만 선택 버튼을 제공한다.
- 브라우저 검사에서 기본 게임을 6.8초에 성공한 뒤 HIGH DECK으로 진입했다.
- 기본 카드 중 사용한 9장이 앞면으로 남고, 기존 11장과 추가된 6~10 카드 20장을 합친 선택 가능 카드 31장을 확인했다.
- HIGH DECK 베팅액 20·40·60과 A~10 숫자 예측의 실시간 확률·반환액을 확인했다.
- 이미 모두 소진된 숫자는 선택 불가 상태로 표시됐다.
- 숫자 2에 40코인을 베팅해 290코인 반환, 558코인 도달 후 점수를 확정했다.
- 점수 확정 직후 최고 코인 기록이 558로 갱신됐다.
- 카드 생성·진입·숫자 정산·점수 확정·부족 코인 종료·마지막 한 장 완주를 포함한 자동 검사 29개와 빌드가 통과했다.

## 2026-09-07 HIGH DECK 재배치와 기록 스크롤

- HIGH DECK 진입 시 사용한 앞면 9장은 기존 위치에 유지하고, 나머지 A~5 카드 11장과 6~10 카드 20장을 한 묶음으로 섞는다.
- 섞인 31장을 모든 빈 위치에 재배치해 아래쪽 두 줄이 6~10 카드라는 위치 정보를 제거했다.
- 낮은 카드와 높은 카드가 위·아래 빈 위치에 섞이고 40장 전체가 중복 없이 유지되는 자동 검사를 추가했다.
- 이번 판 기록은 최대 높이 112px를 넘으면 내부에서만 스크롤하며 새 기록을 자동으로 보여준다.
- 브라우저에서 기록 6건 기준 목록 높이 112px, 실제 내용 145px, 자동 스크롤 위치 33px를 확인했다.
- 자동 검사 30개와 빌드가 통과했고 브라우저 콘솔 오류는 0건이었다.

## 2026-09-07 HIGH DECK 완주 화면과 저장

- 완주 상태의 덱에는 마지막 한 장만 남는데 화면이 이미 사용한 선택 카드 3장을 다시 제거하려 해 렌더링 오류가 발생하던 원인을 수정했다.
- 확률 계산은 베팅·공개 중에만 수행하고, 완주 화면의 선택 카드는 전체 보드에서 찾도록 분리했다.
- 완주 화면에 마지막 남은 카드, 최종 스코어, 최고 코인 기록, 누적 HIGH DECK 완주 횟수와 전체 플레이 시간을 표시한다.
- 저장 형식을 버전 2로 올리고 기존 버전 1 기록은 유지하면서 HIGH DECK 완주 횟수 0회로 자동 변환한다.
- 브라우저에서 기본 게임을 256코인으로 성공한 뒤 HIGH DECK 10라운드를 모두 진행해 마지막 한 장과 완주 화면을 확인했다.
- 완주 시 최종·최고 336코인, HIGH 완주 1회가 표시됐으며, 새로고침 뒤에도 완주 횟수와 최고 코인이 유지됐다.
- 자동 검사 32개와 프로덕션 빌드가 통과했고, 완주와 재접속 과정의 브라우저 콘솔 오류는 0건이었다.

## 2026-09-07 난이도 20회 비교

- 목표 코인만 150에서 130으로 변경하고 각 10회를 동일한 자동 플레이 전략으로 실행했다.
- 150코인은 성공 3/10, 범위 15~291, 중앙값 75.5코인이었다.
- 130코인은 성공 5/10, 범위 15~312, 중앙값 169.5코인이었다.
- 실패 가능성을 유지하면서 HIGH DECK 진입을 더 자주 보여준 130코인을 최종값으로 선택했다.
- 개별 20회 기록과 비교 한계는 `docs/difficulty-results.md`에 보관한다.

## 2026-09-07 저장·효과·공개 안전

- 새 게임의 현재 상태 초기화, 정상 기록 재접속 보존, 빈 값·손상값·이전 버전 복구를 자동 검사했다.
- 결과 애니메이션은 보통 0.36초이며 움직임 줄이기에서 0.000001초로 즉시 감소했다. 설정은 재접속 뒤 유지됐다.
- 소스와 배포 대상에서 API 키·토큰·비밀번호·개인 이메일 등 비밀값·개인정보 패턴 0건을 확인했다.
- 최종 목표 130코인 상태에서 자동 검사 32개와 프로덕션 빌드가 통과했다.
